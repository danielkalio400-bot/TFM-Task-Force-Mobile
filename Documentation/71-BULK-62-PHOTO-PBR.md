Bulk 62 - Live CC0 photographed PBR surfaces for TFM District 01. The new PowerShell importer looks up 2K JPG diffuse, OpenGL normal, roughness texture file URLs from Poly Haven's public metadata API. It saves original photos and a CC0/provenance ledger only in the user's Unity project and invokes a Unity batch Editor command to configure URP Lit maps with smoothness = 1 - roughness, using the alpha channel of a generated MetallicGloss texture. The saved District 01 and original operator assets stay intact. The District builder calls the photo stage after it creates the independent scene, with failure fallback to existing generated materials. Credit: Powered by Poly Haven (when using live API). Node CI does not compile Unity and actual map quality must be reviewed on a graphics device. API reference https://github.com/Poly-Haven/Public-API.
